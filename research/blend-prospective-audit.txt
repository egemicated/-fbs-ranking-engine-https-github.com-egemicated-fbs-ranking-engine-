Frozen numerical design
- Same three deployed components and same common measured FBS cohort.
- Anchored tie-aware midrank percentiles, tolerance 1e-10; singleton = 50.
- Seven fixed models: three standalones, equal-thirds triple, and three
  equal-half pairwise blends. No automatic selection or interim retuning.
- Primary games require both teams to have four prior outcome games and
  four measured Performance games; secondary requires one of each.
- Seven venue-aware probability mappings are exactly those fitted on the
  1,097 established 2018-2019 games in the historical study. They are not
  refitted on future games. The index itself is not a win probability.
- Fixed seven-day forecast horizon avoids grading distant games forever
  against an initial weeks-old forecast under the earliest-capture rule.

Capture checks observed
- Reads existing normalized schedule, primary publication and matching
  Performance publication. There are no provider requests in capture.
- Reconciles parsed input bytes, source hashes, season/team/division and
  completed game sets, paired participants, margins and venue adjustment.
- Requires matching main/Performance snapshot hash and source asOf, exact
  frozen model configurations, finite scores and measured-game counts.
- Capture time is taken after numerical assembly. The CLI has no backdating
  override. Freeze, source cutoff, source fetch and Performance generation
  times must all be at or before capture.
- Only unfinished source FBS-FBS fixtures strictly after capture and within
  seven days are saved; missing Performance is never zero-filled.
- Hashes bind the protocol, producer/configuration pins, input checksums,
  cohort indices/counts, schedule and actual forecast capture timestamp.
- Exclusive writes refuse replacement. Identical reruns retain the first
  actual capture time; different evidence cannot rewrite that observation.
- Wall-clock checks before and after a new write prevent a capture crossing
  kickoff from being retained. Existing valid history is preserved.

Evaluation checks observed
- Verifies the observation checksum, frozen protocol and implementation
  pins, timing, identity, prior counts and primary eligibility.
- Independently checks common-population percentile/midrank spacing,
  equal-weight arithmetic, picks, differences and frozen probabilities.
- Selects the earliest immutable capture per season/game before consulting
  outcome-dependent exclusions. Duplicate checkpoints are one game.
- Conflicting material forecasts at the same capture time fail closed.
- Reconciles actual result participants, venue, subdivision and kickoff.
  A game moved before capture, changed in participants/venue or moved beyond
  the seven-day horizon is explicitly excluded; a later favorable forecast
  cannot replace the excluded earliest one.
- Pending/missing results are not scored as success. Invalid final scores
  and corrupt evidence fail closed.
- All seven models use exactly the same primary or secondary games.
  Ranking ties receive half credit. Probability accuracy, Brier and log
  loss are separate from neutral ordering accuracy.
- Regular/postseason, venue, component-Top25 union and disagreement groups
  use common saved pregame evidence; Top25 boundary ties are included.
- Tracking coverage counts all currently sourced completed FBS-FBS games
  since freeze, including games with no forecast. A failed optional capture
  or setup gap therefore cannot disappear silently from coverage reporting.
